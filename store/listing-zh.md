## 详细描述

关注列表整理工具帮你把关注列表收拾干净：头像网格里逐个挑选，确认名单后再执行，全程有进度、可暂停、可挽回。

### 主要功能

- 头像网格多选：昵称搜索 + B 站关注分组筛选，上千个关注也能快速定位
- 逐条核对：执行前列出完整名单，取关不会通知对方
- 随机间隔 + 风控自动降速：触发风控自动切到保守节奏，连续失败自动熔断
- 可暂停、可中止、可续跑：意外关闭页面后继续未完成的部分，不重复处理
- 误删可挽回：完成页提供「回关本次 N 个」，把刚取关的账号重新关注
- 保护名单：手动锁定 ∪ B 站「特别关注」，名单内账号永不被选中
- 最近关注排除：最近 7 天新关注的账号默认跳过（天数可调）
- 操作记录：开始前自动保存一份计划与结果，可导出 JSON / CSV

### 怎么用

1. 安装后在任意 B 站页面点击工具栏图标打开面板（再点一次关闭）
2. 搜索或筛选要整理的账号 → 勾选 → 下一步 → 核对名单
3. 点「取消关注 N 个」开始执行；执行期间可关闭面板，任务会在页面内继续
4. 完成后会发送系统通知；误删可点「回关本次 N 个」

### 安全与隐私

- 无后端、无统计、无第三方 SDK：所有网络请求只发往 `*.bilibili.com`
- 数据只保存在你自己的浏览器里（`chrome.storage.local`），卸载扩展即清除
- 使用浏览器自带的登录状态，扩展不读取账号密码，也不接触 Cookie 内容
