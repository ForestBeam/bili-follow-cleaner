# 关注列表整理工具

哔哩哔哩（B 站）关注列表批量整理浏览器扩展：头像网格多选、批量取关、进度可控、断点续跑、备份导出。

> **非官方工具**：与哔哩哔哩 / B 站官方无任何关联，未经官方授权。请自行评估使用风险，建议从小批量开始。

## 功能

- 读取本人关注列表，头像网格多选，支持全选 / 清空
- 支持按 B 站关注分组筛选，一键选中整组；也可只看已注销账号
- 执行前自动备份（JSON / CSV），保留最近 3 次，可随时重新下载
- 随机间隔 + 风控自动退避 + 连续失败熔断；触发风控后，本次剩余任务自动切换保守节奏
- 暂停 / 继续 / 停止；意外关闭页面后可断点续跑，不重复处理
- 完成或中止时发送系统通知（可在设置中关闭）
- 保护名单：手动锁定 ∪ B 站「特别关注」分组，受保护账号永不被选中、不被取关
- 最近关注排除：最近 N 天关注的账号默认跳过（默认 7 天，可在设置中改为 0 关闭）
- 昵称搜索 + 滚动加载 + 卡片主页入口，取关前方便核对
- 完成页「回关本次 N 个」：误删可一键重新关注，走同一套节奏与重试
- 工具栏图标再点即关闭面板，Esc 也可关闭；选择自动保留，刷新不丢
- 保护锁在卡片上双向切换；中止任务需二次确认
- 极简设置：执行间隔（标准 / 保守）、单次上限、最近关注天数、保护名单、通知开关、显示原始错误信息

## 安装（桌面版 Edge / Chrome）

1. 获取 `dist` 目录：下载仓库产出的压缩包，或本地执行 `npm install && npm run build`
2. 打开 `edge://extensions`（或 `chrome://extensions`），开启「开发人员模式」
3. 点击「加载解压缩的扩展」，选择 `dist` 目录

商店版本上架后可直接搜索安装。

## 使用

1. 在任意 B 站页面点击工具栏图标打开面板（再点一次关闭）；若当前不是 B 站页面，会自动新开一个 B 站标签页
2. 搜索或筛选要整理的账号 → 选中 → 下一步 → 核对名单后点「取消关注 N 个」；卡片右上角的锁按钮可加入保护名单，再点一次解除
3. 「特别关注」分组的账号会自动保护；最近关注（默认 7 天内）的账号默认不可选
4. 执行期间可关闭面板，任务会在页面内继续（切到后台会变慢但不会中断），完成后通知你；误删可在完成页「回关本次 N 个」

## 隐私

- 无后端、无统计、无外部请求：所有网络请求只发往 `*.bilibili.com`
- 数据只保存在本机浏览器（`chrome.storage.local`）
- 取关使用浏览器自身登录态，扩展不接触账号密码，也不读取 Cookie 内容以外的信息

详见 [PRIVACY.md](PRIVACY.md)。

## 风险提示

- 批量取关可能触发 B 站风控提示。默认参数偏保守：标准间隔 1.5~4 秒，保守档 3~8 秒。
- 建议单次不超过 300 个，必要时分几天完成。
- 取关不会通知对方；若重新关注，对方会收到提醒。
- 回关与取关走同一套随机间隔与风控退避；重新关注可能让对方看到关注提醒。

## 开发

```bash
npm install
npm run watch      # 开发构建（输出 dist/）
npm test           # Vitest 单测
npm run typecheck  # 类型检查
npm run build      # 生产构建
npm run pack       # 构建并产出商店上传用 zip
node scripts/gen-icon.mjs  # 重新生成图标
```

- `src/core/` 纯逻辑（wbi 签名、错误码、退避、任务状态机、备份、设置、存储封装）
- `src/content-main/` 页面世界（MAIN world）fetch 执行器
- `src/content-ui/` 面板 UI、调度 controller、入口 wiring
- `src/background/` service worker：图标点击、补注入、系统通知
- `tests/` Vitest 单测

文档：设计规格 `docs/superpowers/specs/`、实现计划 `docs/superpowers/plans/`、真机清单 [docs/e2e-checklist.md](docs/e2e-checklist.md)。
